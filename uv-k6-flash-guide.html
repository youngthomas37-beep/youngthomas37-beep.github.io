    UV-K6 刷机指南

    把泉盛 UV-K5/K6 刷成 LOSEHU 自定义固件的完整步骤：用 k5prog-win 图形界面或 K5Web 网页刷机，含升级模式进入、备份与注意事项。

    0. 准备

    • 固件文件：本指南以基础版 LOSEHU133.bin（中文，无需扩容）为例；英文版为 LOSEHU133E.bin。K/H 版需要扩容 EEPROM，见相关工具页说明。
    • 先备份原厂固件（强烈建议）：用下面的工具先把当前固件读出来存成文件，万一刷坏可恢复。
    • 关闭占用 COM 口的软件：CHIRP、串口助手、网页串口工具等，避免冲突。
    • 连接：写频线连接电脑，给对讲机开机；Windows 设备管理器里确认出现 COM 口。

    1. 开机模式（按工具区分，别搞错）

    • 用 k5prog-win 时：对讲机正常开机——先关机，再正常开机，不要按 PTT。工具会自己处理升级切换。
    • 用官方升级工具（QSPSUpdater）时：需要长按 PTT 开机进入升级模式（手电筒常亮、屏幕不亮）。

    ⚠️ 如果在 k5prog-win 里看到 radio is in firmware update mode - turn the radio off, then back on whilst NOT pressing the PTT，说明你按了 PTT：关掉对讲机，不按 PTT 正常开机再试即可。

    2. 方法 A：k5prog-win（Windows 图形界面，推荐）

    1. 下载：github.com/OneOfEleven/k5prog-win（解压即用）。
    2. 打开程序，选择 COM 口。
    3. 先备份：点读取（Read）把当前固件/EEPROM 读出来保存。
    4. 选择固件 LOSEHU133.bin，点写入 / 刷写（Write / Flash）。
    5. 等待进度到 100%，期间不要断电、不要拔线。

    标准命令行版 k5prog（piotr022/sergev）只读写 EEPROM、不刷固件；刷固件请用图形界面的 k5prog-win。

    3. 方法 B：K5Web（网页刷机，losehu 推荐）

    1. 用 Chrome / Edge 打开 k5.vicicode.com。
    2. 点连接，在浏览器串口列表里选对应 COM 口。
    3. 若有「备份」功能，先备份原厂固件。
    4. 选择固件文件 LOSEHU133.bin，点刷写，等待完成。

    4. 验证

    1. 重启对讲机，看开机画面（应变为 LOSEHU 的欢迎界面）。
    2. 用本站的 「基础版文字写入」工具 连接，识别到的版本号应含 LOSEHU（不再是原厂如 7.01.09）。
    3. 之后即可用文字工具改写两行开机文字。

    ⚠️ 注意事项

    • 升级过程中绝对不能断电 / 拔线，否则可能变砖。
    • 刷完开不了机：重新进入升级模式，用备份的原厂固件刷回去。
    • 基础版 LOSEHU133.bin 不需要扩容 EEPROM，适合原厂机器；但没有开机图片功能（图片需 K/H 版 + 扩容）。
    • 刷机有风险，请务必先备份、谨慎操作。

    相关工具

    • 基础版开机文字写入：适合没扩容的原厂机器，改写两行开机文字（英文/数字）。
    • 开机画面定制：适合已扩容 + K/H/HS 固件的机器，写图片或把文字渲染进图片。
