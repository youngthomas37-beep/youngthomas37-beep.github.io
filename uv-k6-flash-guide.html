    UV-K6 刷机指南

    泉盛 UV-K5/K6 刷机——先确认硬件版本，V3 和旧版 V1/V2 的刷机方式完全不同，刷错会变砖。

    ⚠️ 第 0 步：确认版本（最重要）

    • 翻到机器背面标签，看有没有「V3」字样；
    • V3（PY32F071）连电脑后，USB PID 通常是 FFFF；旧版（DP32G030）是 0001；
    • 不确定就问卖家，或看购买时间（2025 年后的新机多为 V3）。

    V3 固件和 V1/V2 固件互不通用，刷错会黑屏/变砖。

    一、V3（PY32F071，2025 年后新机）

    刷机入口：叮咚鸡（Dondji）刷机站，网页直刷，无需安装软件（Chrome / Edge）。

    1. 进 BOOT 模式：关机 → 按住 PTT 不放 → 旋转旋钮开机（手电亮、屏幕黑）。
    2. 打开刷机站 → 「刷固件」→ 远程获取或本地选固件 → 刷入。
    3. 刷完重启对讲机。

    刷回原厂：Dondji 菜单「其它 → 恢复出厂 → 原厂 (OEM)」→ 关机 → 用泉盛官方写频软件（QSPortableStationCPS）的「设备 → 升级程序」刷原厂固件。

    救砖：刷机站底部「应急工具箱」提供原厂固件（如 官方固件_K5_V.7.01.09.bin）和 K6 V3 校准文件（calibration_k6v3.dat）。

    首次刷 Dondji 后建议：备份校准 → 刷固件 → 清除数据 → 按需刷字库 → 恢复校准 → 写频。

    二、旧版 V1/V2（DP32G030）

    固件文件以 LOSEHU 基础版 LOSEHU133.bin（中文，无需扩容）为例；英文版为 LOSEHU133E.bin。K/H 版需要扩容 EEPROM。

    开机模式（按工具区分）

    • 用 k5prog-win 时：对讲机正常开机，不要按 PTT。工具会自己处理升级切换。
    • 用官方升级工具（QSPSUpdater）或网页刷机时：需要长按 PTT 开机进入升级模式（手电筒常亮、屏幕不亮）。

    ⚠️ 如果 k5prog-win 提示 radio is in firmware update mode，说明你按了 PTT：关机，不按 PTT 正常开机再试。

    方法 A：k5prog-win（Windows 图形界面）

    1. 下载：github.com/OneOfEleven/k5prog-win（解压即用）。
    2. 打开程序，选择 COM 口；先读取备份当前固件。
    3. 选择 LOSEHU133.bin，点写入/刷写。
    4. 等待 100%，期间不要断电、不要拔线。

    方法 B：K5Web（网页刷机）

    1. 用 Chrome / Edge 打开 k5.vicicode.com。
    2. 连接并选择 COM 口；有备份功能就先备份。
    3. 选择固件文件，点刷写，等待完成。

    ⚠️ 通用注意事项

    • 刷机全程绝对不能断电 / 拔线，否则可能变砖。
    • 刷前备份原厂固件和校准数据（V3 用 Dondji 的「备份校准」，旧版用 k5prog 读取）。
    • 关闭占用 COM 口的软件（CHIRP、串口助手、其他网页串口工具）。
    • 刷完开不了机：V3 重新进 BOOT 模式用 Dondji 刷；旧版重新进升级模式刷回原厂固件。
    • 数据线必须支持数据传输（很多线只能充电）。
