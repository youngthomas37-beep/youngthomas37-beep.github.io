    GUIDE / 指南

    UV-K6 V3 自定义文字

    V3 机器上怎么改「显示的文字」——频道名、开机提示。用叮咚鸡（Dondji）固件自带的菜单和网页写频工具即可。

    能改哪些文字

    • 频道名：菜单 ChName（命名信道），支持中文；也可用 Dondji 刷机站的「写频」页，批量导入 Excel。
    • 开机提示：菜单 BootHnt（开机提示），选项有 Dondji / Beautiful BJ / happy 55th 等。
    • 开机画面（图片）：见 UV-K6 V3 开机画面指南。

    ⚠️ 关于旧的「基础版文字写入」工具

    本站曾提供一个网页工具，直接写 EEPROM 0x0EB0/0x0EC0 的两行开机文字。那是给 旧版 V1/V2 的 LOSEHU 基础版固件用的，对 V3 不适用（V3 是 PY32F071，存储布局完全不同），而且从未在真机验证过，因此已下线。

    V3 用户请用上面的 Dondji 菜单 / 写频页。

    写频批量改频道名

    1. 用 Chrome / Edge 打开 Dondji 刷机站。
    2. 机器正常开机（不是 BOOT 模式），连 USB。
    3. 找「写频」区域：「从设备读取」把现有信道读出来，或在 Excel 里编辑好再「导入 Excel → 写入设备」。
    4. 读写后连接会自动断开，这是正常的防呆设计，重新点一次即可继续。

    写频功能仅适用于叮咚鸡固件；原厂固件请用泉盛官方写频软件。
