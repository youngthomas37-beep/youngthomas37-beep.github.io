钱学森的毕业课题

从地月自由返回，到太阳摄动下的三圈绕月任务。两个版本独立保留，各自说明动力学假设、点火方式与数值验证。

01 / CLASSIC · 保留原版

地月自由返回·经典版

Earth–Moon CR3BP，300 km LEO→TLI→月球飞越→自由返回。保留原来的地月模型、RK45 数值程序与三维视角，不加入太阳或后续推力。

原有版本固定给定初值，不执行完整 differential correction；页面保留这一说明。

02 / POWERED · 新增任务

日地月三圈任务·动力版

太阳差分引力＋有限时长推力＋变质量。从 300 km LEO 出发，月球制动捕获，累计绕月三圈后再次点火，返回地球约 300 km 近拱点。

红色/蓝色表示地心惯性速率增加/降低；可调质量、比冲、推力。提供月球特写、单圈查看、太阳全景与燃料账本。

默认示例的实际验证

初始质量 40 吨，干质量 8 吨，比冲 450 s，推力 450 kN；三圈由月心惯性累计角事件检测，不是重复画图。返回时剩余推进剂约 5.506 吨，总推进 Δv 约 4.7914 km/s。

Java 与网页各自从初猜重新积分、修正并通过对照；独立惯性系积分验证返回近拱点约 300 km。太阳为双圆四体近似，不使用实际日期星历；未模拟地球制动入轨、再入或着陆。

Java 桌面版与源码

Java 版独立实现 RK45、事件定位、差分修正、三次有限点火和变质量模型，并提供 Swing 三维自由相机、播放与燃料/推力侧栏。需要 Java 17 或更高版本。

GitHub Pages 托管静态网页，在线版使用 JavaScript；Java 程序下载后在本机运行，网页不会声称直接执行 JVM。

完整包 ZIP可执行 JARJava 源码运行说明
java -jar SolarLunarMission.jar --gui

# 或直接运行 Java 源码（JDK 17+）
java SolarLunarMission.java --gui

# 输出重新求解的事件记录及全轨迹 CSV
java -jar SolarLunarMission.jar --out mission-output

Java 与网页均采用可调示例火箭；修改参数可能使任务无解或燃料不足，程序会明确报错。
