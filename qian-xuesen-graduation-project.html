01 / 完整方程组

质心旋转无量纲坐标；地球 (−μ,0,0)，月球 (1−μ,0,0)，角速度 n = 1。点质量、圆轨道模型，无大气、太阳摄动和后续推力。

r₁² = (x+μ)² + y² + z²
r₂² = (x−1+μ)² + y² + z²
Ω = (x²+y²)/2 + (1−μ)/r₁ + μ/r₂
ẋ = vₓ, ẏ = vᵧ, ż = v_z
v̇ₓ = 2vᵧ + x − (1−μ)(x+μ)/r₁³ − μ(x−1+μ)/r₂³
v̇ᵧ = −2vₓ + y − (1−μ)y/r₁³ − μy/r₂³
v̇_z = −(1−μ)z/r₁³ − μz/r₂³
C = 2Ω − (vₓ²+vᵧ²+v_z²)
ΔC(t) = C(t) − C(0)

04 / 方法与验证

浏览器实际求解 CR3BP ODE；Dormand–Prince 5(4) 自适应 RK45，绝对/相对容差均为 10⁻¹²，最大步长 0.002 T*。近点事件由相对位置·旋转速度从负到正检测，再在该步内二分并重积分。返地事件只在第 4 天后搜索。播放时间点从前一个积分节点重新做 RK45 步进，实时计算 C 和 ΔC。

本次重新积分验证给定基准参数；没有重新运行完整 differential correction。此参数组作为当前 CR3BP 基准解。差分修正通常调整 θ₀ 和 vTLI，使近月高度及返地高度满足目标；本页面不宣称完成该求解流程，也不冒称拥有此前 Work 已验证的最终 HTML。
