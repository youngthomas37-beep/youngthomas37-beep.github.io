    UV-K6 开机画面定制

    连接泉盛 UV-K5/K6，上传图片或输入呼号，写入对讲机开机画面。纯浏览器直连（Web Serial），无需安装任何软件。

    使用前提

    • 对讲机已刷 LOSEHU xxxK / xxxH / xxxHS 固件（需已扩容 EEPROM ≥1MiB）。
    • 用 Chrome / Edge 打开本页。
    • 写频线连接电脑并给对讲机开机（UV-K6 用 USB-C 数据线；首次使用需装 CH340 串口驱动）。

    使用步骤

    1. 点「连接对讲机」，在浏览器弹出的串口列表里选择 COM 口。
    2. 上传图片，和/或输入呼号文字；预览即最终效果。
    3. 点「写入开机图片」；也可先点「读回当前开机画面」查看当前画面。
    4. 重启对讲机查看效果。

    说明：开机画面为 128×64 单色；照片建议 2:1 横图，文字建议短而大（呼号等）。
