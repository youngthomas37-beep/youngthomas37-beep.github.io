    UV-K6 V3 自定义开机画面

    泉盛 UV-K6 的 V3 版本（PY32F071 芯片）如何换上自己的 128×64 开机图片——用叮咚鸡（Dondji）网页工具，纯浏览器操作。

    ⚠️ 先确认你的机器是 V3

    UV-K6 有多个硬件版本，只有 V3（PY32F071）能用本文的方法：

    • 翻到机器背面标签，看有没有「V3」字样；
    • V3 连电脑后，USB 设备的 PID 通常是 FFFF（旧版是 0001）；
    • 不确定就问卖家，或看购买时间（2025 年后的新机多为 V3）。

    旧版 V1/V2（DP32G030）不要照本文操作，两者固件/存储完全不同。

    步骤

    1. 刷叮咚鸡（Dondji）固件：用 Dondji 刷机站，进入 BOOT 模式（关机 → 按住 PTT → 旋转旋钮开机），选「刷固件」。
    2. 上传开机图片：固件刷好后，在刷机站找「开机图片」区域，选择 PNG / JPG / BMP 图片。工具会自动缩放并转成 128×64 单色位图，可调阈值、反色、预览。
    3. 机器上选 Logo：在菜单里找到 POnMsg（开机画面），把选项设为 Logo。
    4. 重启对讲机，开机时就会显示你上传的图片。

    POnMsg 的选项含义

    选项含义
    None开机不显示画面
    Default固件默认开机画面
    Logo你上传的自定义图片（选这个）

    提示：POnMsg 和 BootHnt（开机提示）、BootSnd（开机音效）、BLTime（背光时间）在同一组菜单里，方便找。

    关于本站原来的「开机画面定制」工具

    本站曾提供一个网页直连写开机画面的工具，它是为 旧版 UV-K5/K6（V1/V2，DP32G030） 写的（写入 EEPROM 0x02080），并且依赖 LOSEHU K/H/HS 固件 + EEPROM 扩容。它从未在真机上验证过，对 V3 也完全不适用，因此已下线。

    如果你用的是 V3，请直接用上面的 Dondji 方案；如果你用的是旧版 V1/V2，建议使用对应固件社区的成熟工具。
