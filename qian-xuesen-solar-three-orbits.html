动力学与推进方程
ρ = (x,y,z), vR = (u,v,w)
r₁ = |ρ + μ ex|
r₂ = |ρ − (1−μ) ex|
Ω = (x²+y²)/2+(1−μ)/r₁+μ/r₂

ρ̇ = vR
u̇ = 2v + Ωx + aS,x + aT,x
v̇ = −2u + Ωy + aS,y + aT,y
ẇ = Ωz + aS,z + aT,z

s(τ) = R[cos φ, sin φ, 0]
φ = φ₀ + (nS T − 1)τ
aS = mS[(s−ρ)/|s−ρ|³ − s/R³]
（直接项 + 质心加速的间接项）

aT,ND = (F/(1000 m)) (T²/D) n̂
dm/dt = −F/(Isp g₀)
dΔv/dt = F/(1000 m)
g₀ = 9.80665 m/s²

TLI: n̂ ∥ 地心惯性速度
LOI: n̂ 反向于月心惯性速度
TEI: n̂ ∥ 月心惯性速度
F = 额定推力 / 0（关机）
太阳采用双圆受限四体近似：地月仍为圆轨道，太阳位置随时间变化；不是实际日期星历。太阳相位是模型输入。太阳引力不消耗燃料，加速也不一定发生在点火期间。


太阳与推力下的误差检查
C = 2Ω − |vR|²
dC/dτ = −2 vR·(aS+aT)
W(τ) = ∫ −2 vR·(aS+aT) dτ
ε = C(τ) − C(0) − W(τ)
C 不再是守恒量；ΔC 本身不能当作数值误差。ε 检查积分的做功平衡。
RK45 自适应 Dormand–Prince 5(4)，拒绝步机制；事件在步内二分、局部重积分。质量、累计 Δv、月心惯性转角、W 与轨迹一同积分。轨迹来自接受状态；动画为 ODE 级数的连续输出。z=0，不制造三维高度。
默认天体与地月距离统一物理比例；增强只放大天体绘制半径。太阳全景以 AU 为单位，地月细节将按真实尺度缩小。
