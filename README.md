# Thomas Young — Personal Website

中英双语个人主页，采用响应式 HTML/CSS 设计，可通过 GitHub Pages 发布。

Bilingual personal website built with responsive HTML and CSS, ready for GitHub Pages.

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/(root)`, then click **Save**.
4. Wait a few minutes, then visit https://youngthomas37-beep.github.io/.

## Local preview

Open `index.html` in a modern browser.
